Instruction

YM Gallery is a retro-inspired portfolio project modeled after the 2006 YouTube interface. This section outlines the metadata tagging conventions used to structure and display media content across the platform.

Legends

Title = Name or title for videos and photos, for example "YMGallery Showcase".

/from/ = Media publisher channel name, for example "/admin/".

(Category) = Category for each media item, for example "(Showcase)".

[Tags] = Key tags for the media, for example "[gaming, photoshop, html]".

{Description} = Description for the media, for example "{Lorem ipsum dolor sit amet..}".

("whats new category") + ;1; = Channel profile picture identifier.

$filter$ = Filter identifier for each projects (Projects page only), for example "$YMGallery projects$".

<link> = Link to Figma project (Projects page only), for example "<https://www.figma.com/...>".

$filter$ + ;1; = Project thumbnail (Projects page only), for example "$YMGallery projects$;1;".

;2; ... = Additional projects image assets (Projects page only).

The following code snippets demonstrate how these metadata tags are combined in practice to format different media types.

Example

Photo = YMGallery Photo /Luthfie Budie/ (Showcase)

Video = YMGallery Showcase /luthfie Budie/ (Showcase) [Web, Gdrive] {Lorem ipsum dolor sit..}

Projects = YMGallery Image 2 /luthfie Budie/ $YMGallery$ ;2;

Projects (Thumbnail) = YMGallery Project /luthfie Budie/ $YMGallery$ ;1; {Lorem ipsum dolor sit..} <https://www.figma.com/...>

P.S. for Project do not put another description and link after putting them in the same $filter$.
